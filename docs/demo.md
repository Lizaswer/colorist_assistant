# Что показать на паре (5–7 минут)

1. **Проблема (1 мин).** Ошибка в формуле стоит мастеру переделки и клиента;
   ColorClick уже есть, но не объясняет логику и не проверяет формулу мастера.
2. **Сквозной сценарий (2–3 мин).** Открыть http://127.0.0.1:8000/
   - Анкета: корни 7, длина 7, седина 30%, кератин, цель 7 холодный → «Рассчитать».
     Показать формулу и объяснение: у каждого шага ID правила.
   - Вкладка «Проверить мою формулу»: 7/3, 60 г, оксид 3% → система находит 3 риска.
   - Цель 9 → отказ: осветление вне рамок MVP.
3. **Проверка на примерах (1–2 мин).** `python scripts/evaluate.py` →
   [отчёт](evaluation/report.md): 4 совпадения и 3 известных ограничения. Честно сказать,
   что случаи пока синтетические, а точность будет измеряться на реальных.
4. **Что дальше (1 мин).** Интервью с колористами, правила бренда, отдельная формула для длины,
   тест на прядь при хне, выводы из критики ([09-critique.md](09-critique.md)).

Прогон 01.10.2026 подтвердил пункты 2–3 в браузере и автотестами (24 passed, 3 xfailed).

## Подготовка

```bash
source .venv/bin/activate        # Windows: .venv\Scripts\activate
uvicorn colorist.api.main:app --reload
```

На Windows в консоли PowerShell, если кракозябры в `demo.py` / `evaluate.py`:

```powershell
$env:PYTHONIOENCODING = "utf-8"
python demo.py
python scripts/evaluate.py
```

Чтобы открыть с телефона в той же Wi-Fi сети: `uvicorn colorist.api.main:app --host 0.0.0.0`,
затем на телефоне `http://<IP ноутбука>:8000/`.
