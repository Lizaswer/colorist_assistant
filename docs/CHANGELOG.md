# Журнал изменений

## 2026-11-17

- Входные граммы зон теперь принимают только конечные положительные числа.
- API проверяет формат кода оттенка и совпадение его уровня с целью.
- Плоский расчёт сохраняет явный код оттенка (`9.26`, `7.43` и т. п.).
- Проверка направления учитывает полный многозначный код оттенка.
- Ошибки расчёта с некорректными значениями возвращаются как HTTP 422, а не как 500.
- Динамический текст в веб-интерфейсе экранируется перед вставкой в DOM.
- Файловые логи переведены из `logs/colorist.log` в Markdown-файл `logs/colorist.md`.
