# Критерии результата

## Гипотеза

Гибридная система, в которой формулу рассчитывают формализованные правила колористики,
а языковая модель объясняет результат, даёт формулы не менее точные, чем чистая LLM
и коммерческие сервисы, но при этом объяснимые и проверяемые.

## Целевая метрика

Не менее **80%** формул гибридной системы колористы оценивают как «верно» или «допустимо».

## Методика проверки

1. Собрать 20–30 реальных случаев от колористов: данные клиента и эталонная формула мастера,
   включая неудачные случаи.
2. Прогнать случаи через три системы: гибридную, чистую LLM без правил и ColorClick.
3. Показать формулы колористам без указания источника: верно / допустимо / ошибка.
4. Сравнить доли верных и допустимых формул.
5. Дополнительно: время расчёта у начинающего мастера с ассистентом и без.

Результат ценен при любом исходе: если чистая LLM окажется не хуже,
это обоснованный вывод о том, нужна ли формализация знаний.

## Критерии приёмки первой версии (сквозной сценарий)

- [x] Мастер заполняет анкету и получает формулу с объяснением по шагам.
- [x] Каждый шаг и каждое предупреждение ссылаются на правило.
- [x] Мастер вводит свою формулу и получает список рисков.
- [x] Случаи вне рамок (осветление, затемнение больше чем на 2 тона) отклоняются с объяснением.
- [x] Все эталонные случаи прогоняются одной командой, результат сохраняется в отчёт.
- [ ] Правила сверены с колористами и заменены значениями выбранного бренда.
- [ ] Не менее 5 реальных случаев в `data/cases`.
