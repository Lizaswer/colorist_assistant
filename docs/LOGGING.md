# Логи

Приложение пишет runtime-логи в `logs/colorist.md`. Файл создаётся автоматически
при первом импорте API или запуске скрипта.

Каждая запись является Markdown-элементом списка:

```md
- **INFO** `api` — POST /health
  _2026-11-17 12:00:00_
```

В лог попадают запросы к калькулятору и проверке формул, выбранная линия,
найденные риски и ошибки внешнего ИИ. API-ключи и содержимое запросов к модели
не записываются. Папка `logs/` исключена из Git, потому что записи могут
содержать рабочие данные клиента.

Для просмотра последних записей:

```powershell
Get-Content logs/colorist.md -Tail 50
```
