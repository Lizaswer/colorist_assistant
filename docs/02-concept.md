# Концепция (спецификация)

Этот документ описывает **что** делает продукт и **зачем** — без технологий.
Он меняется редко. Как это реализовано сейчас — в [03-implementation.md](03-implementation.md).

## Цель

Помочь колористу рассчитать или проверить формулу окрашивания так, чтобы каждое решение
было понятно и его можно было проследить до конкретного правила колористики.

## Принципы

1. **Формулу считают правила, а не языковая модель.** Числа (оттенки, граммы, оксид, время)
   получаются детерминированно. Языковая модель только объясняет и отвечает на вопросы.
2. **Каждое решение объяснимо.** У каждого шага расчёта и каждого риска есть ID правила.
3. **Ассистент — второй взгляд, а не замена мастеру.** Решение остаётся за мастером,
   тест на аллергию обязателен.
4. **Честные границы.** Если случай вне рамок, система отказывает и объясняет почему,
   а не выдаёт формулу наугад.

## Основной путь пользователя (MVP)

1. Мастер заполняет анкету: уровень у корней и по длине, седина, пористость, история волос,
   желаемый уровень и направление оттенка.
2. Система выдаёт формулу: оттенки и граммы, процент оксида и пропорцию, время выдержки.
3. Под формулой — объяснение по шагам со ссылками на правила и предупреждения о рисках.
4. Мастер может ввести свою формулу, и система перечислит найденные в ней риски.

## Рамки MVP

- Один бренд, выбранный по итогам интервью.
- Тон в тон и затемнение на 1–2 тона. Осветления нет.
- Ввод через анкету, без анализа фото.

## Поведение в граничных случаях

| Ситуация | Поведение |
| --- | --- |
| Желаемый уровень светлее исходного | Отказ: осветление вне рамок MVP |
| Затемнение больше чем на 2 тона | Отказ: нужна препигментация |
| Некорректные данные (уровень вне 1–10) | Сообщение, какое поле исправить |
| Хна, кератин, высокая пористость | Формула + предупреждение с правилом |
| Формула мастера не читается | Сообщение об ошибке формата оттенка |

Критерии, по которым понятно, что продукт полезен, — в [04-result-criteria.md](04-result-criteria.md).
