# Риски

Главное преимущество проекта — доступ к практикующим колористам.
Главный риск — скрытые переменные в состоянии волос.

| Риск | Как снижаем | Статус |
| --- | --- | --- |
| Скрытые переменные: пористость, история окрашиваний, седина | Подробная анкета, предупреждения при неполных данных | частично: предупреждения есть |
| Правила черновые, не проверены колористами | Все помечены `TODO(колористы)`; сверка на шаге 2 плана | открыт |
| Небольшой тестовый набор (20–30 случаев) | Честно указывать ограничения, расширять набор после MVP | открыт |
| Эксперты расходятся в оценках | Несколько оценщиков, шкала «верно / допустимо / ошибка» | открыт |
| Проверка формул «на бумаге», а не на волосах | Неудачные случаи из практики, по возможности пилот в салоне | открыт |
| Ответственность за повреждение волос | Без осветления, дисклеймер, тест на аллергию | закрыт в MVP |
| Сильный конкурент ColorClick | Упор на объяснимость, измеренную точность и проверку формулы | открыт |
| Консервативные опытные мастера | Фокус на начинающих колористах | закрыт решением Р3 |

## Найдено при прогоне случаев

| Риск | Случай | Что меняем |
| --- | --- | --- |
| Корни и длина считаются одной формулой | 04-roots-vs-length | Добавить отдельную формулу для длины |
| При хне формула выдаётся вместо теста на прядь | 05-henna | Для хны рекомендовать тест на прядь, а формулу — условно |
| Проверка не видит пепельный нюанс при тёплой цели | 02-darker-warm | Добавить правило о несовпадении направления |

## Из критики в отдельном чате

Разбор: [09-critique.md](09-critique.md). Дата: 01.10.2026.

| Риск | Серьёзность | Решение команды |
| --- | --- | --- |
| Анкета не вписывается в темп смены (К1) | высоко | Проверить на интервью; для пары анкета достаточна |
| Скрытые переменные вне анкеты дают уверенно неверную формулу (К3) | высоко | Не обещать полноту; расширять анкету только после реальных промахов |
| Без бренда нюансы нельзя набрать в тюбике (К4) | высоко | Сверить `knowledge.py` с картой выбранного бренда |
| 20–30 случаев и синтетика завышают «точность» (К6, К7) | высоко | 80% считать только на `verified: true`; текущий отчёт — сценарий, не метрика |
| Слепая оценка знакомыми смещена (К8) | средне | Не показывать источник формулы; нужен хотя бы один внешний оценщик |
| Сравнение с ColorClick может сорваться (К9) | средне | Проверить руками 5 одинаковых анкет |
| Претензия клиента при неверном затемнении/седине (К11) | высоко | Ассистент — совет; осветления нет; тест на аллергию обязателен |
