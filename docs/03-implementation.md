# Реализация (текущая)

Этот документ описывает **как** устроена система сейчас. Он может меняться, пока
не нарушает [концепцию](02-concept.md).

## Архитектура

```
Браузер / телефон ──► FastAPI ──► модуль правил (чистый Python)
                         │              └─ knowledge.py: таблицы и правила с ID
                         └──► explainer: объяснение (шаблон или LLM + кэш)
```

| Часть | Сейчас | Файл |
| --- | --- | --- |
| Интерфейс | Одна веб-страница, работает и с телефона | `colorist/api/static/index.html` |
| API | FastAPI: `/formula/calculate`, `/formula/check` | `colorist/api/main.py` |
| Модуль правил | Чистый Python, без внешних библиотек | `colorist/rules/` |
| Объяснение | Шаблон из шагов расчёта; при `COLORIST_USE_LLM=1` — пересказ языковой моделью с проверкой цифр, кэшем ответов и откатом на шаблон | `colorist/api/explainer.py` |
| Клиент LLM | Anthropic и OpenAI-совместимые API (в том числе AITunnel), только стандартная библиотека | `colorist/api/llm.py` |
| Замер скорости | Время по этапам, режим `--cache` | `scripts/benchmark.py` |
| Эталонные случаи | JSON, один файл — один случай | `data/cases/` |
| Оценка | Скрипт прогона случаев и отчёт | `scripts/evaluate.py` |
| Тесты | pytest; каждый случай — отдельный тест | `tests/` |

## Что пока упрощено

- **Правила черновые** и общие для индустрии, без привязки к бренду. Все помечены
  `TODO(колористы)` в `knowledge.py`.
- **Одна формула на всю голову**: корни и длина не различаются.
- **Нюансы в общей нотации** (/0 натуральный, /1 пепельный, /3 золотистый);
  у выбранного бренда нумерация может отличаться.
- **Нет базы данных и архива клиентов.**
- **Языковая модель необязательна**: по умолчанию объяснение собирается по шаблону; пересказ моделью включается переменной окружения (см. README). Диалога с моделью пока нет.
- **Кэш ответов модели живёт в памяти одного процесса**: после перезапуска сервера он пуст, между процессами не общий.

## Планируемые изменения

| Что | Когда | Почему |
| --- | --- | --- |
| Правила выбранного бренда | после интервью | Черновые значения не проверены (критика К4) |
| Отдельная формула для длины | после пары / сверки с мастером | Случай 04, критика К5 |
| Тест на прядь при хне вместо готовой формулы | после пары | Случай 05 |
| Правило C-DIRECTION-MISMATCH в проверке | после пары | Случай 02 |
| LLM в объяснениях | сделано 10.10.2026 | Замер: [evaluation/performance.md](evaluation/performance.md) |
| Диалог с LLM по готовой формуле | после пары | Живые ответы на вопросы мастера |
| Короткий ответ модели | следующая оптимизация | Гипотеза: время вызова растёт с длиной ответа (848 символов) |
| База данных, архив клиентов | после первой оценки | Нужно для повторных визитов |
| Мобильное приложение (React Native + Expo) | после проверки ядра | Веб-страницы хватает для первой версии |
