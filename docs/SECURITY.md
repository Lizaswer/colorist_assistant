# Безопасность

- `.env` не должен попадать в Git; для настройки используйте `.env.example`.
- Если API-ключ уже показывался в журнале, терминале или внешнем сервисе,
  отзовите его в панели провайдера и создайте новый.
- `/assistant/chat` расходует внешний API-ключ сервера. Не публикуйте приложение
  напрямую в интернет без аутентификации, ограничения частоты запросов и прокси.
- Логи не содержат ключ и полный текст запросов к модели, но могут содержать
  технические параметры расчёта; храните `logs/` с ограниченным доступом.
