# Документация MVP

## Границы

Текущая реализация следует ограничениям исходного README: один бренд, тон-в-тон
и затемнение до двух уровней, без осветления, без фото. Формула вычисляется
детерминированными правилами; API лишь отдаёт результат и шаблонное объяснение.

## Правила

Все правила имеют ID в `colorist/rules/knowledge.py`. Шаги расчёта и риски
ссылаются на эти ID, поэтому тест может обнаружить необъяснимое решение.

## Важно

Правила сейчас являются синтетической демонстрационной моделью. Перед реальным
использованием их нужно заменить/проверить по технической карте конкретного бренда
и интервью с практикующими колористами. Тест на аллергию и инструкция производителя
обязательны.
